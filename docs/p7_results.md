- **The evidence gate matters most:** without data-quality checks, exact matches on the test split fall to a third.
- **Baselines matter:** without them, more cases abstain.
- **The physical model matters only when baselines are unrepresentative** (history: heatwave and degraded baselines).
- **The SLMs cannot do the diagnosis:** both collapse to a fixed answer (mostly `none`, the first option listed), giving 10-15/17 confidently wrong. This was zero-shot without examples, the weakest fair test, but it supports keeping analytics deterministic.

## What P7 does not cover yet

- **ARM target:** every latency and memory figure here must be re-measured on a 2-core ARM board (Graviton `t4g.small` or a Pi pinned to 2 cores) under one 2 GB limit.
- **Real faults:** none of the recorded vehicles has a labelled thermal fault, so real-world diagnostic accuracy is unknown.
- **Independent questions:** the routing test set was written by the same author as the rules.
- **Experiment A** (input representation ablation) was not run; Experiment B's SLM variants cover the most important part (raw vs Δ-Signature input).
